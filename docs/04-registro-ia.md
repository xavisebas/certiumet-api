# 04 · Registro de uso de inteligencia artificial

**Herramienta principal:** Claude (Anthropic), modelo Claude Opus 5.5, versión web, octubre de 2026
**Responsable de la revisión:** Xavier Guaygua
**Regla aplicada:** no se ingresaron datos personales reales, credenciales ni información interna de la universidad. Todos los datos del caso (cifras de estudiantes, pedidos y personas) son supuestos o ficticios (supuesto A4).

La IA se usó como apoyo para redactar, ordenar, generar código y revisar. Las decisiones del caso (tema, base de datos, alcance, trabajo individual e idioma) las tomó el estudiante, y cada salida se contrastó con la transcripción de las clases, la rúbrica, la bibliografía del módulo y, desde la semana 2, con una ejecución real (Spectral, ruff, import-linter o pytest) antes de aceptarla.

**Decisión:** Aceptado = se usó tal como salió; Modificado = se usó después de corregir defectos; Rechazado = no se usó.

## Lo que no se aceptó de la IA

- Ningún dato numérico del caso se tomó como real: las cifras del supuesto A3 son estimaciones.
- La revisión cruzada de las vistas C4 no la hizo la IA; la debe hacer un compañero del módulo (ver `02-vistas-c4/README.md`).
- Las opciones de tema y de base de datos que no se ajustaban al caso se rechazaron (filas 1 y 2).
- La propuesta de escribir el código en inglés se rechazó (fila 11, ADR-004).
- La separación de respuestas con `oneOf` se dejó para después (fila 14).
- La IA no se usa como control automático de la cadena: sus respuestas cambian entre ejecuciones y no dan código de salida (matriz del `08`).
